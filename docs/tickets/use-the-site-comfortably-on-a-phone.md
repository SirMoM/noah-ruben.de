# As a user, I want to use the site comfortably on my phone

## Goal

The site should remain easy to browse and interact with on a phone-sized screen.
This story is about the mobile projects experience, especially the filter controls and the amount of effort needed to narrow down results on touch devices.

## Acceptance criteria

- [ ] On a phone-sized viewport, the projects filters are easy to find and use
- [ ] Filter controls are comfortable to operate with touch input and do not feel cramped
- [ ] The mobile flow for narrowing down projects feels efficient without losing the terminal-like style
- [ ] Desktop behaviour on `/projects` stays unchanged
